# Figma assets

This directory contains the image layers exported from the supplied desktop and mobile Figma frames. Desktop and mobile crops are separate where the design uses different framing. `title-*.png`, `service-*.png`, and `stat-*.png` preserve the exact lettering of the design's display fonts.

`Manrope.ttf` and `BodoniModa.ttf` are variable fonts from the official [Google Fonts repository](https://github.com/google/fonts) under the Open Font License.
