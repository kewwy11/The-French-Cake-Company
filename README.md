# The French Cake Company

A React landing page built from the supplied desktop and mobile Figma frames.

## Run locally

```sh
npm install
npm run dev
```

Page sections live in separate files under `src/components`. Base styling is in `src/styles.css`; Figma measurements and responsive adjustments are in `src/figma-fidelity.css`, `src/hero-best-about.css`, and `src/midpage-fidelity.css`.

The Figma photos, logo, and display lettering are included locally in `public/assets`. The design's Gibs and CCS Belvare lettering is preserved as transparent PNG exports while headings remain accessible HTML text. Manrope and Bodoni Moda are bundled locally from the official Google Fonts repository.
